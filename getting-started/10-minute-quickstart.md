## Schnellstartschritte

1. Besuchen Sie https://www.restoflow.ch und eröffnen Sie ein Konto
2. Sobald Sie sich im Admin-Dashboard befinden, klicken Sie auf „Neues Restaurant erstellen“.
3. Geben Sie Ihre Restaurantdaten ein und erstellen Sie das Restaurant
4. Klicken Sie auf Ihr neues Restaurant, um das Restaurant-Dashboard anzuzeigen
5. Besuchen Sie im linken Menü den Abschnitt „Menüs“.
6. Erstellen Sie ein Menü, erstellen Sie eine Kategorie und erstellen Sie dann darunter ein Standardgericht
7. Klicken Sie im linken Menü auf „Bestellungen“, um die Bestellverwaltungsoberfläche anzuzeigen
8. Öffnen Sie Ihren Online-Shop in einem neuen Tab, indem Sie im linken Menü auf „Shop besuchen“ klicken
9. Geben Sie eine Bestellung über Ihre Website auf
10. Sehen Sie auf Ihrer Bestellseite, wie die Bestellung automatisch eingeht. Wählen Sie die Bestellung aus und versuchen Sie, den Bestellstatus oder die Wartezeit zu ändern. Verwenden Sie die Auswahl „Aktionen“, um den Testauftrag zu löschen, wenn Sie fertig sind

## Was kommt als nächstes?

An diesem Punkt können Sie das System nach Ihren Wünschen anpassen und mit der Annahme von Bestellungen beginnen. Wir empfehlen Ihnen, die Artikel in diesem Abschnitt weiterzulesen. Sie erfahren, wie Sie das System Ihren Anforderungen entsprechend konfigurieren und Aufträge detailliert verwalten.
