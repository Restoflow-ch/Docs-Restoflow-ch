# So markieren Sie Artikel als „Nicht vorrätig“

### Schritte:

1. Melden Sie sich als Admin unter admin.restoflow.ch an.
2. Wählen Sie aus der Kontenliste das Konto aus, das Sie aktualisieren möchten, und klicken Sie auf „Verwalten“.

![](<../.gitbook/assets/unknown (31).png>)
3. Gehen Sie im Menü auf der linken Seite zum Dashboard „Menüs“.

![](<../.gitbook/assets/unknown (30).png>)
4. Öffnen Sie Ihr Menü und suchen Sie den Artikel, den Sie als **Ausverkauft** markieren möchten.
5. Aktivieren Sie das Kontrollkästchen neben dem Element.
* Ein Popup mit der Bezeichnung „Aktionen“ wird angezeigt.
6. Wählen Sie „**Kein Lagerbestand**“.

* Der Status des Artikels wird im Frontend aktualisiert und Kunden können ihn nicht bestellen.

![](<../.gitbook/assets/unknown (28).png>)

![](<../.gitbook/assets/unknown (29).png>)
7. Um das Element wieder aktiv zu machen, wiederholen Sie die gleichen Schritte und wählen Sie „**Verfügbar**“.
