# Kaufen Sie einen Domainnamen

## Der Prozess

Der Kauf und die Einrichtung einer eigenen Domain ist ein sehr einfacher Vorgang, der etwa 15 Minuten dauert. Die folgende Anleitung hilft Ihnen dabei, dies mit [https://www.namecheap.com](https://www.namecheap.com) zu tun, da dies unser empfohlener Domain-Registrar ist.

1. Besuchen Sie die Namecheap-Website unter [https://www.namecheap.com](https://www.namecheap.com)
2. Verwenden Sie das Domänennamen-Suchfeld in der Mitte der Seite, um nach einem Domänennamen zu suchen
3. Fügen Sie den Domainnamen Ihrer Wahl Ihrem Warenkorb hinzu
4. Klicken Sie rechts auf die Schaltfläche „Warenkorb anzeigen“, um mit dem Bezahlvorgang fortzufahren
5. Wir empfehlen, die Option „WhoisGuard“ zu deaktivieren, da diese für öffentliche Unternehmen nicht ideal ist.
6. Klicken Sie auf der rechten Seite auf die Schaltfläche „Bestellung bestätigen“.
7. Schließen Sie Ihre Bestellung ab, indem Sie ein Konto erstellen und Ihre Zahlungsdaten eingeben.

{% hint style="info" %}
Sie können sich das folgende YouTube-Video ansehen, um eine Videoanleitung dazu zu sehen – [https://www.youtube.com/watch?v=Zbcn4skYXqM](https://www.youtube.com/watch?v=Zbcn4skYXqM)
{% endhint %}

Sobald Sie eine Domain erworben haben, müssen Sie die Schritte in unserem anderen Artikel „Einrichten einer benutzerdefinierten Domain“ ausführen. Um diese Schritte ausführen zu können, müssen Sie auf die DNS-Einstellungen Ihrer Domain zugreifen. Auf Namecheap können Sie dies tun, indem Sie:

1. Melden Sie sich bei Namecheap an und gehen Sie zu Ihrem Konto-Dashboard
2. Wählen Sie im linken Menü die „Domains-Liste“.
3. Wählen Sie die Schaltfläche „Verwalten“ neben Ihrem Domainnamen
4. Navigieren Sie in Ihren Domain-Einstellungen zur Registerkarte „Erweitertes DNS“.
5. Klicken Sie auf „Neuen Eintrag hinzufügen“, um einen DNS-Eintrag zu erstellen.&#x20;

{% hint style="warning" %}
Möglicherweise müssen Sie einige bereits festgelegte Standarddatensätze entfernen, um unsere hinzuzufügen
{% endhint %}

## Zusätzliche Informationen

### **Was ist eine Webdomäne?**

Eine Domain ist eine beliebige Webadresse, beispielsweise ist „google.com“ eine Domain.

### **Ihre Subdomain**

Ihr Shop wird über Ihre eigene, einzigartige Subdomain zugänglich sein, die Sie auswählen können. Ihre Subdomain wird immer unter „example.restoflow.ch“ gehostet. Jede Subdomain muss eindeutig sein und wird nach dem Prinzip „Wer zuerst kommt, mahlt zuerst“ vergeben.

### **Benutzerdefinierte Domäne**

Eine benutzerdefinierte Domain ist ein Domainname, den Sie kaufen und mit unserem Service verbinden. Sie können jeden verfügbaren Domainnamen wie „IhrUnternehmen.com“ registrieren und mit unserem Service verbinden. Auf diese Weise können Kunden direkt über Ihren Domainnamen Ihr Online-Bestellsystem finden.

Oft ist es wünschenswert, einen eigenen Domainnamen für Ihr Geschäft zu haben, um Ihre eigene Marke und Ihr Unternehmen besser zu bewerben. Es ist viel einfacher, Ihren Kunden mitzuteilen, dass sie Sie unter „order.yourbusiness.com“ statt unter „yourbusiness.restoflow.ch“ finden.
