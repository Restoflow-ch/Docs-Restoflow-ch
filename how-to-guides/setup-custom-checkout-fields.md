# Richten Sie benutzerdefinierte Checkout-Felder ein

{% embed url="https://youtu.be/qe9rAjuTE3w" %}

* Gehen Sie zu Einstellungen &gt; Dienstleistungen
* Wählen Sie den Dienst aus, dem Sie ein benutzerdefiniertes Checkout-Feld hinzufügen möchten.
* Wählen Sie „Benutzerdefinierte Checkout-Felder“
* Klicken Sie auf „Neues Feld hinzufügen“.
* Passen Sie das Feld nach Bedarf an.
* Klicken Sie auf Speichern und überprüfen Sie das Feld.
