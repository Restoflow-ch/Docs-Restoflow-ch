# So erstellen Sie einen Store-API-Schlüssel

{% embed url="https://drive.google.com/file/d/1vSIZaq8LE5RAzVCRrMVr_95IroUxrZrG/view?usp=sharing" %}

### Schritte:

1. Melden Sie sich bei Ihrem Konto an[ https://admin.restoflow.ch/login](https://admin.restoflow.ch/login)
2. Navigieren Sie zu **Entwickler**
3. Klicken Sie auf **API-Schlüssel erstellen**, um das Formular zu öffnen
4. Fügen Sie **Name** zum Label des API-Schlüssels hinzu, um die Identifizierung zu erleichtern
5. Wählen Sie aus, welches Restaurant Zugriff auf diesen Schlüssel haben soll&#x20;
6. Speichern



{% hint style="danger" %}
Bitte senden Sie eine E-Mail an [info@restoflow.ch](mailto:info@restoflow.ch) oder nutzen Sie die Chat-Support-Funktion, um Hilfe bei der Verwaltung dieser Funktion zu erhalten.
{% endhint %}
