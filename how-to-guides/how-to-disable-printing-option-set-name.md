# So deaktivieren Sie den Namen des Druckoptionssatzes

### Schritte:

1. Melden Sie sich bei Ihrem Konto an[ https://admin.restoflow.ch/login](https://admin.restoflow.ch/login)
2. Gehen Sie zu **Menüs** > **Optionssätze**

<figure><img src="../.gitbook/assets/unknown (24) (1) (1).png" alt="" width="563"><figcaption></figcaption></figure>

3. Öffnen Sie den Optionssatz, den Sie nicht drucken möchten, indem Sie auf das Symbol **Bearbeiten** klicken.

<figure><img src="../.gitbook/assets/unknown (25) (1) (1).png" alt="" width="563"><figcaption></figcaption></figure>

4. Aktivieren Sie unter **Allgemein** die Option **Name des Druckoptionssatzes deaktivieren.**

<figure><img src="../.gitbook/assets/unknown (26) (1) (1).png" alt="" width="563"><figcaption></figcaption></figure>

5. Klicken Sie auf **Speichern**.
