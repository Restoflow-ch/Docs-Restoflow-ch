# Wie Benutzer die Sprache im Frontend ändern können

Die Standard-Store-Einstellungen ermöglichen den Store-Benutzern die Auswahl von Sprachen, um zwischen der Standardsprache zu wechseln.  Klicken Sie in der Benutzeroberfläche einfach auf das Dropdown-Menü „Sprache“ und wählen Sie die gewünschte Sprache aus, wie unten dargestellt.
