# So konfigurieren Sie Druckereinstellungen (ESCPOS-Text / ESCPOS-Bild) in Restoflow

### Schritte:

1. Melden Sie sich als Admin unter admin.restoflow.ch an.
2. Suchen Sie in der Liste der Konten das Konto, das Sie aktualisieren möchten, und klicken Sie auf „**Verwalten**“.

![](<../.gitbook/assets/unknown (25).png>)
3. Klicken Sie im Menü auf der linken Seite auf „**Einstellungen**“.

![](<../.gitbook/assets/unknown (24).png>)
4. Wählen Sie „**Quittungsdruck**“ und dann den Drucker aus, den Sie konfigurieren möchten.

![](<../.gitbook/assets/unknown (23).png>)
5. Öffnen Sie die Registerkarte „**Druckeinstellungen**“.

![](<../.gitbook/assets/unknown (22).png>)
6. Wählen Sie unter „**ESCPOS-Drucktyp**“ Ihren bevorzugten Modus aus:
* **Nur ESCPOS-Text** – Höhere Druckgeschwindigkeit; Empfohlen für einfache Textbelege.
* **ESCPOS-Bild** – Erforderlich, wenn Sie ein Logo oder grafische Elemente drucken möchten.<br>

**Hinweis**: Die Optionen können je nach gewähltem Drucktyp variieren. Passen Sie die Einstellungen entsprechend den Fähigkeiten Ihres Druckers an.<br>
7. Nachdem Sie Ihre Einstellungen angepasst haben, klicken Sie auf „**Speichern**“.
