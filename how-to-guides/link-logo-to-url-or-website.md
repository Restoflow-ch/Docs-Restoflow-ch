# Logo mit URL oder Website verknüpfen

Schritte:

1. Melden Sie sich bei Ihrem Konto an [https://admin.restoflow.ch/login](https://admin.restoflow.ch/login)
2. Sobald Sie angemeldet sind, klicken Sie auf „**Verwalten**“.

<figure><img src="../.gitbook/assets/Screenshot 2025-11-11 at 1.38.22 PM.png" alt="" width="375"><figcaption></figcaption></figure>

3. Gehen Sie zu **Einstellungen**

<figure><img src="../.gitbook/assets/Screenshot 2025-11-13 at 3.36.55 PM.png" alt="" width="375"><figcaption></figcaption></figure>

4. Gehen Sie zu **Website > Top-Navigationsleiste > Logo-Link**

<figure><img src="../.gitbook/assets/Screenshot 2025-11-17 at 8.13.26 AM.png" alt="" width="375"><figcaption></figcaption></figure>

5. Fügen Sie die **URL/Website** hinzu, um das Logo-Bild zu verlinken, wenn darauf geklickt wird. Stellen Sie sicher, dass Sie http:// oder https:// angeben.
6. **Speichern**









{% hint style="danger" %}
Bitte senden Sie eine E-Mail an [info@restoflow.ch](mailto:info@restoflow.ch) oder nutzen Sie die Chat-Support-Funktion, um Hilfe bei der Verwaltung dieser Funktion zu erhalten.
{% endhint %}
