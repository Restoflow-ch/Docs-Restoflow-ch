# Landing Page einrichten

Durch die Auswahl eines Standorts werden Kunden sofort zur Bestellseite dieses Geschäfts weitergeleitet.

\
So richten Sie eine Landingpage ein:

1. Melden Sie sich bei Ihrem Konto an [https://admin.restoflow.ch/login](https://admin.restoflow.ch/login)
2. Gehen Sie zur Landingpage

<figure><img src="../.gitbook/assets/Screenshot 2025-11-16 at 1.27.13 PM.png" alt="" width="375"><figcaption></figcaption></figure>

3. Füllen Sie die Felder unter „Allgemein“ und „Website“ aus, um Ihre Landing Page einzurichten

<figure><img src="../.gitbook/assets/Screenshot 2025-11-16 at 1.52.55 PM.png" alt="" width="375"><figcaption></figcaption></figure>
