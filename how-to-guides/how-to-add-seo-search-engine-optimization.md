# So fügen Sie SEO (Suchmaschinenoptimierung) hinzu



### Schritte:

1. Melden Sie sich bei Ihrem Konto an [https://admin.restoflow.ch/login](https://admin.restoflow.ch/login)
2. Gehen Sie zu Einstellungen > Website > Suchmaschinenoptimierung

    <figure><img src="../.gitbook/assets/Screen Shot 2023-10-09 at 8.16.45 AM (1).png" alt=""><figcaption></figcaption></figure>
3. Geben Sie die Details ein und klicken Sie dann auf „Speichern“.

    <figure><img src="../.gitbook/assets/Screen Shot 2023-10-09 at 8.24.26 AM (1).png" alt=""><figcaption><p>Google typically displays the first 50-60 characters</p></figcaption></figure>
4. Sie können auch Google Analytics-Tracking in Ihre Bestellseite integrieren, um Besucher zu verfolgen. Weitere Informationen zu Google Analytics finden Sie unter diesem Link [https://www.restoflow.ch/features/google-analytics/](https://www.restoflow.ch/features/google-analytics/).
