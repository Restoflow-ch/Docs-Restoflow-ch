# Zahlungen akzeptieren

## Empfohlen

Wir haben hart daran gearbeitet, das beste Zahlungserlebnis zu schaffen, ohne Kompromisse bei der Sicherheit einzugehen. Unser Stripe+-Angebot ermöglicht die Akzeptanz von Kreditkarten, Google Pay und Apple Pay.

{% hint style="success" %}
[stripe+-integrated-zahlungen.md](../stripe+-integrated-payments.md "mention")
{% endhint %}

Diese Funktion wird in [diesen Ländern](https://stripe.com/global) unterstützt.

## Beliebte Alternativen

**Bargeld** – Dies ist standardmäßig aktiviert

**Karte -** Dies ist eine nicht integrierte Option, die standardmäßig aktiviert ist.

**Benutzerdefiniert** – Beschriften und erstellen Sie Ihre eigene nicht integrierte Zahlungsoption.
