# So fügen Sie Fußzeilensymbole in Restoflow hinzu

### Schritte:

1. Melden Sie sich als Admin unter admin.restoflow.ch an.
2. Suchen Sie in der Kontoliste das Konto, dem Sie eine Fußzeile hinzufügen möchten, und klicken Sie auf „**Verwalten“**.

![](<../.gitbook/assets/unknown (17).png>)
3. Klicken Sie im Menü auf der linken Seite auf „**Einstellungen“**.

![](<../.gitbook/assets/unknown (16).png>)
4. Klicken Sie auf die Registerkarte „**Website“**.

![](<../.gitbook/assets/unknown (15).png>)
5. Scrollen Sie nach unten zum Abschnitt „Fußzeile“.

**Hinweis**: Stellen Sie sicher, dass der Fußzeilenbereich sichtbar ist (wenn es einen Schalter zum Ausblenden von Abschnitten gibt, stellen Sie sicher, dass dieser deaktiviert ist).

![](<../.gitbook/assets/unknown (14).png>)
6. Geben Sie unter „Logos“ das Logo ein und klicken Sie, um die verfügbaren Standardsymbole anzuzeigen.
7. Wählen Sie die Symbole aus, die Sie in der Fußzeile anzeigen möchten.
8. Klicken Sie auf „**Speichern**“, um die Änderungen zu übernehmen. Wenn es erfolgreich ist. Es werden die Symbole im Frontend angezeigt.

![](<../.gitbook/assets/unknown (13).png>)
